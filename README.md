# MuteGuard

A lightweight Windows app that automatically mutes selected applications on specific audio outputs.

I made MuteGuard to fix an annoying Discord screen-sharing echo issue with **Elgato Wave Link 3**, where people watching my stream could hear their own voices.

MuteGuard runs quietly in the system tray and automatically keeps selected audio sessions muted, helping prevent that echo without losing game or video audio when the correct outputs are selected.
